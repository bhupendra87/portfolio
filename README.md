# Portfolio (Angular)

Personal portfolio for Bhupendra Yadav. Angular standalone components, no backend.

```bash
npm install
npm start                                   # dev server
npx ng build --configuration production     # output: dist/portfolio/browser
```

All content is in `src/app/data/portfolio.data.ts`. Deployment steps: see `DEPLOYMENT.md`.
